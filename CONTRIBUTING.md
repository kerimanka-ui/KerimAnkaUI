# Feedback and contributions

Before opening an issue, check whether the same problem has already been reported.
For a bug, include the KerimAnka UI version, Forever client build, class and faction,
Blizzard or Bartender4 action bars, exact reproduction steps, expected behavior,
actual behavior, and any complete Lua error. Mention relevant optional addons.

For a visual problem, include a screenshot, screen resolution and UI scale.
Hide private chat and other personal information before attaching a screenshot.
Do not post account credentials or an unreviewed SavedVariables/WTF archive.

English reports help the widest audience. If English is difficult, describe the
problem in your preferred language and keep game option names or error text intact.

For a suggestion, describe the problem it would solve and the proposed behavior.
A suggestion does not require a code contribution.

For code contributions, discuss substantial behavior changes in an issue first.
Keep changes focused and explain how they were tested in the target client.
