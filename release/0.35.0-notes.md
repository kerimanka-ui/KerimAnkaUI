# KerimAnka UI 0.35.0 — Classic Era support

Classic Era support is now included alongside the existing Forever client.

- Ready layouts for all nine Classic classes, with backed-up Blizzard and optional Bartender4 profile transfer.
- Unified layout editor with quick settings, previews and save/cancel.
- Combined bags and bank, recorded inventories and item cooldown counters.
- Classic swing timers, Rogue combo points, player cast bar and energy/mana ticks.
- Minimap coordinates and clock/day-night controls.
- Optional World latency beside FPS (off by default), plus name/font and custom panel-color improvements.

Download **KerimAnkaUI-0.35.0-complete-suite.zip** and extract its nine folders directly into `Interface/AddOns`.
Preserve your WTF/SavedVariables when updating. The package selects separate loaders for Forever (16001) and Classic Era (11509).

Classic settings are separate from Forever. These new Classic features have not been ported to Forever. Retail is not supported.
Ready layouts target 1920 x 1080; Classic layouts were prepared at 100% UI scale. Automatic UI-scale adaptation is not included.

Report issues with your version, client build, class and action-bar provider via [GitHub Issues](https://github.com/kerimanka-ui/KerimAnkaUI/issues).
