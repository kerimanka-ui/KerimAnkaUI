# KerimAnka UI 0.40.6 — Settings search and interface fixes

This update targets **WoW: Forever (1.60.1)**. The combined suite download preserves **Classic Era 0.37.0 unchanged**. Existing settings and recorded history are retained.

- **Settings search:** find supported controls across the suite in the selected panel language, with all nine panel languages supported. Search all settings or the current category, jump to the relevant page and tab, expand the needed group and highlight the control. Cursor, unit frames, bags, Hunter settings, threat, minimap, quests, Action Tracker, damage meters, bar appearance, class art, chat, sounds and interface settings are covered where available. Searching does not change a setting. Data/history deletion and profile import/export actions are outside this search.
- **Chat:** fix a conflicting alpha-hook loop when hiding chat controls that could cause a C stack overflow and repeated errors.
- **Bags:** keep the loot window above the visible bag window, restore its prior layer on close and allow dragging the unprotected bag window during combat. Native protected item, sorting and resizing restrictions remain in place.
- **Money display:** use native gold, silver and copper icons in bag wallets, character money lists and the economy view, with icons sized to the text.
- **Hunter range:** add optional approximate PvE range displays, including a single-number estimate when the available evidence supports it. These options are off by default. Wide or unknown ranges retain interval/fallback text; this is not exact coordinate-based distance measurement.
- **Unit frames:** expand player/target buff and debuff positioning, separation and priority controls, and align the live and preview layouts. Player/target vertical distance is shown as an outward distance from 0 to 250; pet and horizontal controls retain their existing behavior.
- **Mail income:** improve matching of delayed mail-failure notifications to confirmed wallet changes without merging distinct sales. Retain the optional `/kamaildebug` support recorder, **off by default** and bounded in memory. Recording starts only when explicitly enabled; personal reports and SavedVariables are not distributed. Existing historical ledger rows are not rewritten.
- **Quest journal:** retain the game-approved QuestJournalRC1 behavior, stable category order and quest menus. Use native quest-header interaction where available and the existing details-opening fallback for uncovered quests. Experimental route/native test commands are removed. This does not claim full native-header coverage or a taint root-cause fix.
- **Settings:** add a sound-shortcut size control and complete related merchant-setting translations.

**Verification and limits:** the settings search, QuestJournalRC1 and mail collector were approved in the author's installed game setup. Other included changes retain their recorded gameplay checks; this is not exhaustive coverage of every class, locale, combat sequence or long session. QuestJournal/map/Edit Mode taint, native damage-meter restricted-value issues, restricted-combat aspect detection and previously documented intermittent bag/chat limitations remain under investigation. Chat CPU/FPS behavior, broader aura-layout gameplay coverage and PvP range behavior are not fully verified.

Independent products, Quest Call Lab, Private Capture Boot, Private Diagnostics, suite private Boot links, personal records and test fixtures are excluded. CurseForge uses the existing tagged-source webhook route; no duplicate manual ZIP upload is required.
