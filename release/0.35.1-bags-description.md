# KerimAnka Bags

A standalone bag and bank interface for **WoW Classic Era**, with three selectable
designs: Classic, Compact, and Leather & Metal.

- Combined bags and bank, search and sorting.
- Item quality, quest-item highlights and cooldown displays.
- Recorded inventories, visited-bank snapshots and character money records.
- Adjustable bag layout and a settings panel available from the bag gear button or `/kabags`.
- Nine settings languages and all required KerimAnka fonts/media included.

**KerimAnka UI is not required.** The full suite already includes the bag feature.
If both are enabled, the suite takes priority. Saved settings are separate and
are not automatically copied between editions. The first release supports one
independent KerimAnka edition at a time. Other bag replacements retain control
when detected; use one bag replacement at a time.

Classic Era only. Retail and Forever are not supported by this independent build.
Existing inventory/bank records are read-only snapshots, not live remote access.
Report issues at https://github.com/kerimanka-ui/KerimAnkaUI/issues .
